# tests

Тесты AetherOrbis. На фазе 0 роадмапа каталог содержит только структуру.

С фазы 1 здесь появляются:

| Группа | Что проверяет |
| --- | --- |
| Контрактные тесты | соответствие выдачи компонентов контрактам `docs/standards/` |
| Негативные тесты gates | явный `ZERO` при недостаточном контексте, сохранение отброшенных источников |
| Тесты конфигураций | добавление направления без изменения кода |
| Тесты телеметрии | наличие события на каждом переходе |
