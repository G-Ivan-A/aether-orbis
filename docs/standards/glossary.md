# Глоссарий AetherOrbis

Единственный источник истины для терминов проекта. Контракты и ADR **НЕ ДОЛЖНЫ** переопределять
термины — они ссылаются сюда. Термины уровня экосистемы наследуются из `standards/glossary.md`
Хаба ([hybrid-Intelligence-lab](https://github.com/G-Ivan-A/hybrid-Intelligence-lab)).

| Термин | Определение |
| --- | --- |
| Acquisition | Приобретение внешних источников: сбор, нормализация, фиксация происхождения. |
| Analysis | Компонент-потребитель, выполняющий предметное рассуждение поверх поставленного контекста. |
| Claim | Утверждение, извлечённое из источника, обязательно сопровождаемое `evidence` и `confidence`. |
| Confidence | Числовая оценка уверенности в элементе извлечения, `0.0`–`1.0`. |
| Context Package | Единица передачи данных от AetherOrbis к Analysis, описанная контрактом достаточности. |
| Direction (направление) | Тема исследования, заданная YAML-конфигурацией без изменения кода модулей. |
| Evidence | Свидетельство происхождения: `source`, `fragment`, `retrieved_at`. |
| Extraction | Извлечение сущностей, связей и утверждений из нормализованного текста. |
| Graph Builder | Единственный компонент, решающий, что становится ребром графа. |
| Human-in-the-loop | Точка вмешательства человека на gates; в MVP — заглушка с логированием. |
| Ingestion | Модуль сбора источников. |
| Model Router | Слой выбора модели по роли операции и требуемому качеству. |
| `NOT_OBSERVED` | Связь не найдена в исследованном материале. Не эквивалентно «связи не существует». |
| `OBSERVED` | Связь подтверждена извлечённым evidence. |
| Parser | Многомодульный компонент приобретения, извлечения, предварительной оценки релевантности и структурирования внешних данных с сохранением происхождения. Не HTML-парсер. |
| Provenance | Прослеживаемость элемента данных до конкретного фрагмента конкретного источника. |
| Raw / Source Store | Хранилище сырого и нормализованного материала источников, вне репозитория. |
| Relevance Gate | Переход, разделяющий материал на релевантный и сохраняемый как метаданные. |
| Research Profile | YAML-описание направления: тема, критерии релевантности, пороги. |
| Source Intelligence | Накопленные сведения об отброшенных источниках: метаданные, summary, причина отбраковки. |
| Sufficiency Gate | Переход, определяющий, достаточно ли контекста для рассуждения. |
| Telemetry | Сквозная фиксация стоимости, токенов, латентности и confidence по переходам. |
| `UNCERTAIN` | Данных недостаточно либо они противоречивы. |
| `ZERO` | Явный отказ системы отвечать по причине недостаточности доказательств. |
