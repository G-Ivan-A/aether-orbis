# Product Vision — AetherOrbis

Структура по Product Vision Board (профиль `product-profile.md` Хаба
[hybrid-Intelligence-lab](https://github.com/G-Ivan-A/hybrid-Intelligence-lab)).

## Проблема

Исследовательские пайплайны на LLM выдают правдоподобный текст без прослеживаемости: вывод нельзя
проверить, стоимость растёт по объёму собранного шума, а при неполном контексте модель не
отказывается отвечать, а достраивает недостающее.

## Аудитория

| Сегмент | Потребность |
| --- | --- |
| Исследователь / аналитик | проверяемый контекст с ссылками на источники |
| Аналитические компоненты экосистемы Хаба | контекст через формализованный контракт |
| Владелец продукта | предсказуемая стоимость прогона и наблюдаемость |

## Ценность

- Каждое утверждение прослеживается до фрагмента источника.
- Явный отказ `ZERO` вместо галлюцинации при нехватке данных.
- Отброшенные источники сохраняются как Source Intelligence и переиспользуются.
- Новое направление исследования добавляется YAML-конфигом, без изменения кода.
- Стоимость управляется маршрутизацией моделей по ролям операций.

## Границы

Входит: сбор, извлечение с провенансом, оба gate, представления граф/вектор, телеметрия, API.

Не входит: предметная аналитика, поиск общего назначения, построение графа внутри парсера,
человеческая модерация как обязательный шаг MVP (заглушка, обязательна с S2).

## Метрики успеха

| Метрика | Цель MVP |
| --- | --- |
| Направлений на одной кодовой базе | 2, различаются только YAML |
| Доля claims с валидным evidence | 100 % |
| Отброшенные источники, сохранённые как метаданные | 100 % |
| Воспроизводимый `ZERO` при обеднённом сборе | покрыт тестом |
| Покрытие переходов телеметрией | 100 % |
