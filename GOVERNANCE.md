# Governance — AI-assisted работа в AetherOrbis

Документ описывает правила работы ИИ в репозитории. Человеческий workflow — в
[`CONTRIBUTING.md`](CONTRIBUTING.md). Governance экосистемы наследуется из
[hybrid-Intelligence-lab](https://github.com/G-Ivan-A/hybrid-Intelligence-lab) и здесь не дублируется.

## Operating modes

| Режим | Что разрешено | Что требует человека |
| --- | --- | --- |
| Assist | правки документации, конфигураций, тестов, рефакторинг | merge |
| Build | реализация задач роадмапа в рамках существующих контрактов | merge, изменение контрактов |
| Design | предложение ADR и изменений контрактов | принятие решения (`accepted`) |

Автономное изменение `main`, релизы и развёртывание — вне зоны ИИ.

## Disclosure

PR, подготовленный с участием ИИ, **должен** сообщать об этом в описании. Поле `ai-generated` в
frontmatter **запрещено** стандартом Хаба — раскрытие делается в PR, а не в артефакте.

Непроверенные утверждения помечаются как допущения; источники указываются ссылками.

## Self-review checklist для AI-агента

- [ ] Изменение не нарушает границы зон: Parser ≠ Graph Builder ≠ Analysis.
- [ ] Контракты не переопределяют термины — ссылка на [`docs/standards/glossary.md`](docs/standards/glossary.md).
- [ ] Нормативная лексика контрактов соответствует RFC 2119 / BCP 14.
- [ ] Frontmatter соответствует классу артефакта и словарю статусов.
- [ ] Имена файлов проходят `tools/validate-file-naming.sh`.
- [ ] Утверждения о внешних фактах подкреплены ссылками.
- [ ] В диффе нет секретов, ключей и runtime-данных.

## Data boundaries

ИИ **не имеет права** помещать в репозиторий или в контекст публичных сервисов: ключи API, учётные
данные, персональные данные, непубличные данные заказчиков. Содержимое источников хранится в
Raw / Source Store вне git.

## Escalation

| Ситуация | Действие |
| --- | --- |
| Требуется изменение контракта или ADR | остановиться, предложить ADR, дождаться решения владельца |
| Обнаружено противоречие между документами | зафиксировать в issue, не «чинить» молча |
| Недостаточно контекста для решения | задать вопрос в issue, а не выбрать допущение |
| Подозрение на утечку секрета | немедленная эскалация владельцу, см. [`SECURITY.md`](SECURITY.md) |
